# Muhammad Adil — personal website

This is a GitHub Pages/Jekyll site with a browser-based content editor powered by Pages CMS.

## Add content without editing code

1. Open [Pages CMS](https://app.pagescms.org/).
2. Sign in with the GitHub account that owns this repository.
3. Select `m-adilk/m-adilk.github.io`.
4. Choose **Certificates & Achievements**, **Gallery Albums**, or **Extra Pages**.
5. Click **New**, fill in the form, upload files, and save.

Pages CMS commits the content to GitHub. GitHub Pages then publishes it automatically; this commonly takes one or two minutes.

New certificates and gallery albums appear on the homepage and receive individual pages. Extra pages receive a URL at `/pages/url-name/`. Uploaded files are stored in `assets/uploads/`.
